# AEMXSC Demo Base

This is the **shared base template** for AEMXSC Edge Delivery Services demos. It's an AEM Block Collection
foundation (blocks, component models, DA-compatible config) that every new customer demo repo is stamped from
via GitHub's "Use this template."

## DA compatible

This repo has been _slightly_ modified to be compatible with DA's live preview.

## Don't set this up by hand

Building a demo from this template, installing AEM Code Sync, and wiring up Document Authoring are all covered
step by step in the **`xsc-team-docs`** playbooks — don't follow ad hoc steps here, they'll drift out of sync.

1. First time on the team? Start with [`readiness.md`](https://github.com/AEMXSC/xsc-team-docs/blob/main/readiness.md).
2. Building a demo? Use [`create-eds-repo.md`](https://github.com/AEMXSC/xsc-team-docs/blob/main/create-eds-repo.md) —
   it creates your customer repo from this template and completes the rest of the setup.

See the [xsc-team-docs README](https://github.com/AEMXSC/xsc-team-docs) for the full playbook index.
